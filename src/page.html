千早爱音 · 招式表

方向以面向对手为准，换边后左右反转。拳：J / H / K；脚：N / M / 逗号，依次为轻、中、重。支持方向指令，也可以使用单键快捷技。

G / 2P Delete 消耗50%能量立即变身凑企鹅，无前摇，可马上移动和接招，持续20秒，到期恢复高松灯。不能叠加或刷新时间，暂停和命中停顿冻结计时。C / 空中F 飞踢（10%）；U 糖哭反击（15%），防住一次正面攻击并回击，起手、背后和投技可破；I hey?（10%）；T 唐笑（20%）；L 咕咕嘎嘎（40%）；B 投技。基础攻击支持站立、蹲下和空中。

G / 2P Delete：凑企鹅立即变身（50%，持续20秒，无前摇）。
灯：I 微光音符（20%，伤害12）；T 诗句回声（30%，伤害18）；L 迷途之歌（60%）连续唱出三段音波，每段原始伤害8，连击存在衰减。均需在地面或平台施放，受击会停止后续歌声，已发出的音符继续前进；可被防御、钢板和飞行物抵挡。2P使用小键盘4 / Enter / 3，手机有对应按钮。

素世 G / 2P Delete：归心·自愈消耗35%共鸣，按胸凝神0.7秒后恢复24生命（上限100），总收招1.2秒，独立冷却12秒。限地面施放，满血不会消耗能量；起手可被打断，打断后不回血，能量与冷却仍消耗。
素世 T / 2P小键盘 Enter 消耗50%共鸣，在地面召唤三个小天素罗，自动轮流追击，持续10秒。每次突袭原始伤害4，可被防御（磨血1）和爱音正面钢板抵挡；召唤物不会给素世回充共鸣。持续期间不能重召或叠加，暂停冻结，回合结束与重开清除。练习按钮沿用当前所选角色。

蹲防挡下段，站防挡跳跃攻击与越拍踢。投技可破防。普通技命中后可接更重拳脚或必杀，必杀命中可接大招；连续命中伤害会衰减。表中为单次原始伤害，大招合计48。爱音 U 召唤钢板（20%共鸣），持续3秒、40耐久，可抵消正面打击和音符弹；超出耐久的伤害仍会扣血，背后攻击和投技可绕过。爱音投技改为 B。T 释放 TGW 音波（30%共鸣），地面发动，伤害22、强击退；会被格挡、钢板和对方飞行物挡下。
C 闪光突刺（15%）命中可接 V 切分三连击（25%），V 末段命中可接 P 大招。空中 F / ↓+重脚发动流星俯冲踢（15%，需离地一定高度）；空中普通技命中可接 F。俯冲命中落地收招短，落空或被挡收招更长。
方向连按两次可冲刺。练习模式共鸣收招后自动回满，木桩最低保留1生命。
