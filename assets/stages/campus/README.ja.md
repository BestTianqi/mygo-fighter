# 学園と MyGO のステージ素材

新しいステージを 9 枚追加し、既存の 6 枚と合わせて 15 枚になりました。新しい背景はすべて、ネット上で公開されている『BanG Dream! Girls Band Party!』の背景素材から取得し、元の PNG のまま保持しています。実行時はそれぞれのフォーカス位置を基準に 16:9 へ切り抜き、WebP に圧縮してオフライン HTML に埋め込みます。元のシーンの代わりに似た学校写真を使うことはしていません。

| ------------------------------------ | ----------- | -------------------------------------------------- |
| 花咲川女子学园（花咲川女子学園）     | bg00003     | 花壇の低い足場、中央の高い回廊、両側の回り込み足場 |
| 羽丘女子学园（羽丘女子学園）         | bg00010     | 多段の連続足場、上層の連絡通路                     |

| 羽丘·学校天台（羽丘女子学園 屋上）   | bg00012     | 機材台、柵付きの足場                               |

| 大台阶·夜景（大階段・夜景）          | bg01008     | 高さの異なる階段、側面の回り込み足場               |

背景はいずれも原作ゲームのアートで、権利は元の権利者に帰属します。本プロジェクトのオリジナルでも CC ライセンスの素材でもありません。元の URL、ダウンロード日、サイズ、SHA-256 は [sources.json](sources.json) にあります。

ステージの確認：

- [背景画像ギャラリー](https://bandori.fandom.com/wiki/Girls_Band_Party%21_Background_Images)：花咲川の校門、羽丘の校門／屋上、CiRCLE の練習スタジオ。
- [Morfonica 第 1 話のストーリーデータ](https://bestdori.com/assets/jp/scenario/band/021_rip/Scenarioband6-001.asset)：月ノ森のシーン。`bg00473` は「月ノ森女子学園 庭園」に対応します。
- [MyGO 第 7 話のストーリーデータ](https://bestdori.com/assets/jp/scenario/band/045_rip/Scenarioband8-007.asset)：`bg00010` は「羽丘女子学園 校門前」に対応します。
- [MyGO 第 8 話のストーリーデータ](https://bestdori.com/assets/jp/scenario/band/045_rip/Scenarioband8-008.asset)：`bg01007` は「大階段」に対応し、`bg01008` は同じシーンの夜景です。
- [MyGO 第 16 話のストーリーデータ](https://bestdori.com/assets/jp/scenario/band/045_rip/Scenarioband8-016.asset)：`bg00918` は「RiNG スタジオ」に対応します。

地形はこのゲームのために独自に設計したプレイ用のレイアウトです。足場のラインと衝突の高さが一致しているため、台に飛び乗る、↓＋ジャンプで台をすり抜けて落ちる、斜面や階段を歩くといった動きができます。低地、高台、カメラは既存のバトルルールを使っています。新しい各ステージの最上層は、CPU が実際に登るテストを通過しています。
