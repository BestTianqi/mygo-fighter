# 凑企鹅の春日影と Mortis スキル調整

日付：2026-10-22。完全な出典、分P、開始・終了時刻、チェックサムは `sources.json` にあります。

## 凑企鹅（ペンギン形態）

- 音源は[川崎仁仁菜：🐧春日影 | 司凤版🐧](https://www.bilibili.com/video/BV1XTad6oE8F/?p=1)、第1分P、cid 42329377775、80.0–88.1秒を切り出したものです。同ページの第2分Pは高松燈のカバー版で、今回は使っていません。
- 音声はページに「司凤版」と記された二次創作の歌唱で、44.1 kHz モノラル MP3、96 kbps、ラウドネスを揃えて短いフェードを入れています。ペンギンの既存の映像イラスト、動作アトラス、勝利の奥義アートは差し替えていません。
- P は100を消費し、合計8.3秒。自身の胴の中心から5つの円形音波を 0.5 / 1.7 / 2.9 / 4.1 / 5.3 秒に出します。各音波は半径650まで広がり、高低層をまたげます。各対象は1つの音波につき1回だけ被弾します。ガードなしのダメージは固定10で、コンボ減衰や Counter 補正の影響を受けません。ガード・钢板・無敵回避のルールは維持します。音波は召喚物や通常の飛び道具に消費されません。
- 通常形態のU/I/Oは引き続き「诗句回声」「微光音符」「迷途之歌」、ペンギンのUは「糖哭反击」、Iは近距離の「hey 震慑」、Oは前方への3連突進です。ペンギンは前＋Uの飛び蹴りと↓＋Iの「唐笑」を維持します。形態制限はシミュレーション層と技表の両方で分離し、ペンギン中は重複する変身入口を隠します。

## Mortis ステージ形態

H は引き続き50を消費して20秒持続し、既存のステージ衣装素材は残します。制服形態のスキルは変更ありません。

| キー | 技                    | 共鳴 | 挙動                                                                                                  |
| ---- | --------------------- | ---- | ----------------------------------------------------------------------------------------------------- |
| U    | Mortis·替身代演       | 20   | 100後退し、前方の身代わりが2段攻撃、基礎ダメージ 8 / 12                                               |
| I    | 我不会弹吉他·装死反击 | 25   | 0.1–0.65秒のカウンター受付。正面の攻撃を1回防ぐと22ダメージの反撃を出す。投げと背後からの攻撃で崩せる |
| O    | 不要解散·牵线留人     | 30   | 前方の目標位置に予告後、琴線が落下。同じ足場の範囲内に18ダメージを与えて引き戻す上段攻撃              |
| P    | Mortis·双生剧场       | 100  | 体の両側の人形・吊り糸・3幕の攻撃。前の2幕は引き寄せ、終幕は打ち上げ、基礎ダメージ 8 / 12 / 28        |

設計の根拠は Mortis の代演・守護・バンド解散への恐れで、ゲームオリジナルの技です。アニメ本編にこれらの戦闘能力があるという意味ではありません。公式キャラクター参考：[若葉睦 / Mortis](https://anime.bang-dream.com/avemujica/character/mutsumi/)、原作第4話の公式あらすじ：[Bushiroad プレスリリース](https://bushiroad.com/media/36ab2fe8e377b1ba)。

Mortis ステージ形態のPは[月夜-涙の原作映像](https://www.bilibili.com/video/BV1j8f5YdE6n/?p=2)、第2分P、39.29–46.28秒を使っています。日本語の文字起こしで位置を特定し、祥子に話しかける実際の映像も確認しました。映像はミュートのまま独立ボイスを重ねて音の重なりを避け、通常形態は元の「不曾觉得乐队开心」の映像を使い続けます。

追加したメディアはすべてオフライン HTML に埋め込み、効果音のオン／オフ、一時停止からの再開、被弾／ラウンド時のクリアは既存システムをそのまま使います。
