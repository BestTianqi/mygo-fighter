# Mortis ステージ形態の独立スキルボイス

| キー         | ボイス               | 出典と切り出し                                                                                                               |
| ------------ | -------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| U 替身代演   | 短い悲鳴             | [睦头人尖叫一小时纯享](https://www.bilibili.com/video/BV1uPf5YCE73/)、cid 28039907968、0–0.95秒                              |
| I 装死反击   | 「安心して」         | [Ave Mujica Mortis：「小睦已经死掉了」第2P](https://www.bilibili.com/video/BV1j8f5YdE6n/?p=2)、cid 28038924686、40.7–42.45秒 |
| O 牵线留人   | 制御を失った長い叫び | 悲鳴動画の0.95–3.05秒                                                                                                        |
| H 戴面具变身 | 「嫌い」             | Mortis 映像の第2P、36.5–39.8秒                                                                                               |

変身後のP「Mortis·失控尖叫」は、O で使う0.95–3.05秒の長い叫びの録音を使います。ユーザーの要望により映像の切り出し開始を2秒前倒しし、元の開始0.95秒では2秒に足りないため、原映像の0秒から2.1秒までを切り出して、元の区間長と原速を保っています。1秒以内に5層の拡散する音波を出します。必殺技の悲鳴は独立したチャンネルを使い、続けて出すスキルでも途切れません。一時停止後は停止位置から再開します。元の「睦和她的乐队由我守护」の台詞映像は素材ソースディレクトリに残しています。

Mortis のステージ衣装、口の動き、字幕、悲鳴の場面をフレーム単位で確認し、日本語 ASR を位置特定の補助に使いました。悲鳴はアニメ第4話の解散宣告後に Mortis が制御を失う場面で、原映像の冒頭10秒だけを読み取っています。作者、正確な時間、SHA-256 は sources.json に記録しています。

4つとも原速・原音程のまま、音量を-19 LUFSに揃え、ごく短いフェードイン／アウトを入れています。H とステージ形態の投げは形態ごとに合わせ、通常形態は元のボイスを使い続けます。↓Uの「我只有两岁」、↓Iの「我要吃汉堡」の素材は残しています。チャンネルは相手から独立しており、ミュートと一時停止からの再開に対応し、リスタート／ラウンド終了でクリアされます。元の出典ファイルは残し、実行時はパッケージ済みのローカルメディアファイルを使います。
