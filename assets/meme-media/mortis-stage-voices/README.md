变身后 P「Mortis·失控尖叫」使用 O 的 0.95–3.05 秒长啸录音，并配对同一视频、同一起止时间的画面，总长2.1秒，配合一秒内五层扩散声浪。大招尖叫使用独立声道，接续技能不会截断；暂停后从暂停处续播。音视频都保持原速；原“睦和她的乐队由我守护”对白视频保留在素材源目录。

已逐帧核对Mortis的演出服、口型、字幕及尖叫场景，日语ASR辅助定位。尖叫为动画第4集解散宣告后的Mortis失控片段，仅读取源视频前10秒。作者、精确时间和SHA256记录在 sources.json。

四段均保持原速原调，统一音量至-19 LUFS并做极短淡入淡出。H与演出形态投技按形态匹配，普通形态继续使用原语音；↓U两岁、↓I汉堡的素材保留。声道独立于对方，支持静音与暂停续播，重开／回合结束清理。原有来源文件保留，运行时使用已打包的本地媒体文件。
