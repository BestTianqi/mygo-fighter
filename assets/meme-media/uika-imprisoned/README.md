# 三角初华变身音乐

来源：[Ave Mujica - Imprisoned XII (Official Music Video)](https://www.bilibili.com/video/BV1Ep91YPEQo/)，官方账号 MyGO_AveMujica，cid 28735767349，第1P。

使用官方MV开头0–20秒作为H变身音乐，保持原速与音高，调整背景音量并在首尾淡入淡出，随HTML离线打包。来源与文件哈希记录于 sources.json。

初华H成功变身时播放一次，独立于技能语音，普攻、技能及普通受击不会打断。暂停及返回菜单暂停音乐，继续时接续播放；变身结束、静音、重开和回合结束停止。双人初华各有独立声道。其他角色保留原有变身音效。
