# 初華の変身音楽

出典：[Ave Mujica - Imprisoned XII (Official Music Video)](https://www.bilibili.com/video/BV1Ep91YPEQo/)、公式アカウント MyGO_AveMujica、cid 28735767349、第1P。

公式MVの冒頭0–20秒をH変身の音楽として使い、原速・原音程のまま、背景の音量を調整して冒頭と末尾にフェードを入れ、HTML のオフラインパッケージに含めています。出典とファイルハッシュは sources.json に記録しています。

初華のH変身が成功したときに1回だけ再生し、スキルボイスとは独立しています。通常攻撃・スキル・通常の被弾では途切れません。一時停止やメニューへ戻ると音楽も止まり、再開時は続きから再生します。変身終了・ミュート・リスタート・ラウンド終了で停止します。2人の初華はそれぞれ独立したチャンネルを持ちます。他のキャラクターは元の変身効果音を維持します。
