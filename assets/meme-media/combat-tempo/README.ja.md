# 戦闘テンポとボイス調整

- 愛音 TGW：出典は[爱音のTGW丰川集团](https://www.bilibili.com/video/BV1srFZecETK/)、投稿者「编新述旧」、第1P、cid 28169736175、27.15–30.85秒を切り出しています。原映像のキャラクター・字幕・音声を照合済みで、`sonic`（↓＋I）の独立ボイス `meme_0_tgw` に接続しました。元の出典・時間・ハッシュは sources.json にあります。
- 燈ペンギンPは `recordings/penguin-p.mp3` の旧音源に戻し、音声は原速で再生、旧映像も残したまま原速で再生します。50/230/410/590/770ms に5層を出し、各層はガードなしなら固定10ダメージです。攻撃の硬直は合計1500msで、音声は自然に再生し切れます。
- 初華の通常形態とステージ形態のPは合計1000msで、80ms後に始動し、入力方向へ毎秒600ワールド単位で這います。100/280/460/640/820ms に各10ダメージ、コンボ減衰なし。這いは体・地形・足場の端で止まります。しゃがみガードを続けると低姿勢ガードを維持します。
- 初華のフィニッシュアートは、既存の[必殺技の出典映像](https://www.bilibili.com/video/BV1oLVXzFEUW/)から3.6秒（原映像で53.8秒）を切り出し、x=300/y=150/w=240/h=160 でクロップしたもので、2種類の衣装のラウンド勝利画面に使います。
- 愛音以外の必殺技は動作タイミングを半分にし、初華の戦闘時間は1秒です。必殺技の映像と音声はすべて元ファイル・原速に戻し、スキル発動で加速しません。映像と必殺技ボイスは硬直や後続の通常攻撃から独立しており、再生し切って自然に終わり、一時停止から再開でき、キャラクター変更・リスタート・ラウンド終了でクリアされます。そよの制圧は引き続き2秒で、ラウンド精算の長さは元の設定のままです。
- 通常攻撃のダメージは全体に0.75を掛けて整数化し（強攻撃キャラの数値も同期）、硬直を80ms延ばしました。攻撃側はスキル命中で+2共鳴、通常攻撃命中は+12に戻し、ガードは+1、必殺技と召喚物は引き続きエネルギーを回復しません。被弾側のエネルギー回復は元の設定のままです。すべてのダッシュ／ブリンクは10共鳴を消費し、実際に発動したときだけ差し引きます。

音声キャッシュは tools/build_meme_assets.py が生成し、演出メタデータは manifest.json に記録されます。旧素材は出典確認のために残しています。
