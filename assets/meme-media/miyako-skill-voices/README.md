# 藤都子小技能语音

U／I／O 改用藤都子本人直播的三段短句，大招 P 继续使用原版「临兵斗者皆阵列在前」录音、视频及奥义图。

| 键位 | 配音 | 原片时间 |
| --- | --- | --- |
| U · 分镜飞页 | 完成啦！ | 1.60–4.38 秒 |
| I · 伏笔机关 | 原谅一下啦～ | 66.70–68.12 秒 |
| O · 截稿线 | 太棒了！ | 111.62–113.30 秒 |

来源：[草女士家的耳廓狐 ·【中字/藤都子】直播画了波堤巧克酱，对自己最新力作发表感想](https://www.bilibili.com/video/BV1Cbn66MEPj/)，原直播链接见上传者简介：[藤都子绘画直播](https://www.youtube.com/watch?v=2h5SuCM4f1s)。中文字幕与虚拟形象用于核对台词和说话人，ASR 仅辅助定位。

录音保持原速，统一为 44.1 kHz 单声道 MP3，归一化采用 `loudnorm=I=-18:TP=-3:LRA=7`，首尾做短淡入淡出；已检查成品音量。来源、CID、时间段与原片指纹保存在 `sources.json`。旧版小技能录音仍保留在 `assets/meme-media/recordings/`。

`tools/build_meme_assets.py` 从该目录覆盖 U／I／O 的录音，投技继续沿用 O 的语音别名；战斗参数不变。
