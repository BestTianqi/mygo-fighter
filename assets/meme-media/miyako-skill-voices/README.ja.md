# 藤都子のスキルボイス

U／I／O は藤都子本人のライブ配信からの3つの短い台詞に変更し、必殺技 P は引き続きオリジナルの「临兵斗者皆阵列在前」の録音・映像・奥義アートを使用します。

| キー         | ボイス       | 原映像の時間     |
| ------------ | ------------ | ---------------- |
| U · 分镜飞页 | 完成啦！     | 1.60–4.38 秒     |
| I · 伏笔机关 | 原谅一下啦～ | 66.70–68.12 秒   |
| O · 截稿线   | 太棒了！     | 111.62–113.30 秒 |

出典：[草女士家的耳廓狐 ·【中字/藤都子】直播画了波堤巧克酱，对自己最新力作发表感想](https://www.bilibili.com/video/BV1Cbn66MEPj/)、配信元のリンクは投稿者の概要欄にあります：[藤都子绘画直播](https://www.youtube.com/watch?v=2h5SuCM4f1s)。中国語字幕とアバターで台詞と話者を確認し、ASR は位置特定の補助にのみ使いました。

録音は原速のまま、44.1 kHz モノラルの MP3 に統一し、正規化は `loudnorm=I=-18:TP=-3:LRA=7`、冒頭と末尾に短いフェードを入れています。完成品の音量も確認済みです。出典・CID・時間帯・原映像のフィンガープリントは `sources.json` にあります。旧版のスキル録音は `assets/meme-media/recordings/` に残しています。

`tools/build_meme_assets.py` がこのディレクトリから U／I／O の録音を上書きし、投げは引き続き O のボイス別名を使います。戦闘パラメータは変更ありません。
