# 薇欧拉：动画原声

全部素材来自梦限大MewType官方发布的[薇欧拉角色CM](https://www.bilibili.com/video/BV11uK36xEs2/)，CID `39994722827`。4秒处角色介绍卡写明「薇欧拉 / Viola」「CV 本渡楓」；后续近景中可核对深绿色姬发、侧丸子、金绿色眼睛和发夹。所选片段均为薇欧拉本人的动画语音，没有直播主旁白或合成语音。

| 入口 | 原片区间 | 官方字幕／对白含义 | 游戏改编主题 |
| --- | --- | --- | --- |
| U | 0.00–3.15秒 | 我是大家的妹妹薇欧拉啦 | 镜头闪拍 |
| I | 4.72–8.17秒 | 是吗，没有传达到啊 | 剪辑陷阱 |
| O | 9.05–13.65秒 | 那小阿拉蕾保持这样就好了 | 话术推击 |
| ↓＋U | 24.70–26.48秒 | 做得真好 | 剪辑声波 |
| P | 16.85–20.90秒 | 这个数字，感觉会成为不错的引爆点呢 | 剪辑放送 |

P保留4.05秒完整句和同一时间区间的视频，均为原速。不要把视频或录音加速到战斗出招时长；20.6秒前停止会切断句末的「そう」。其开头画面是阿拉蕾与薇欧拉同框，声音仍来自薇欧拉，随后切至她的发言近景。P的日文自动转写在「数字／起爆剤」附近有错误，所以元数据不把该转写冒充精确原文，提供可见的官方中文字幕作为证据。

奥义图为同一场景20.10秒的薇欧拉近景，存于 `assets/finish-art/viola-anime-ignition.webp`。来源、时间、说话者证据及每个源媒体SHA-256见 `sources.json`；`install.json`提供角色15的slot和variant接线资料。镜头、剪辑和放送的攻击效果是本游戏对动画角色的改编设计，不是原作超能力设定。

安装时在 `tools/build_meme_assets.py` 的 `CHARACTERS` 尾部添加 `viola`，再用 `normalize_clip(row, catalog, 15, row['slot'], row['voice'])` 读取此目录的 `sources.json` clips，分别写入角色15的 `slots` 和 `variants`；`throw`复用O。最后按现有打包流程安装运行媒体与奥义图。不要覆盖或重制原有角色素材。
