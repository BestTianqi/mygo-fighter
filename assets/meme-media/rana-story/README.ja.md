# 楽奈：アニメ音声と終奏の映像

公式30秒「キャラクター紹介CM・要楽奈篇」から7つの実際のアニメ音声を選びました。原配信元は[BanG Dream Channel☆](https://www.youtube.com/watch?v=YE6sJdXyrKo)で、[公式キャラクター資料](https://anime.bang-dream.com/mygo/character/rana/)により声優が青木陽菜であることを確認しています。今回のダウンロード元は[花园多惠Officialによる原CMの転載、第3P](https://www.bilibili.com/video/BV1i14y1U7DP/?p=3)、CID `1173143631` です。転載アカウントは公式アカウントではないため、記録では原配信元とダウンロード元を明確に区別しています。

↓＋Uの打ち上げはUを再利用し、空中↓＋Oの急降下はバイバイを、↓＋Iの調弦は満足を再利用します。すべての区間は原速・短い台詞そのままの長さで、AI 音声や配信者のナレーションは使っていません。話者は白いショートヘア、金と青のオッドアイ、元のカット、見える口の動きで確認し、日本語の単語単位の文字起こしを切れ目の補助に使いました。CM 内で自動文字起こしが不明瞭だった短い台詞は1つ採用せず、それによって原作の台詞を創作することもしていません。

P「结束了吗？·野猫终奏」の映像と録音はどちらも原CMの連続した23.15–26.60秒です。楽奈の口元の寄りからパフェを持つ全身の顔へ切り替わり、2つの台詞とその間の間（ま）を残しています。映像は戦闘での発動に合わせて加速せず、録音も後続スキルで途切れません。奥義アートは同じ区間の26.00秒の楽奈で、`assets/finish-art/rana-anime-ending.webp` に保存しています。

`sources.json` は技のmove、voice、BV/CID/分P、時間、出典、話者の根拠、SHA-256 を区間ごとに記録しています。`install.json` はキャラクター3のslots/variantsの接続参考です。旧版の抹茶パフェや「有趣的女人」などの素材は残し、元のキャラクター絵と動作はここでは変更していません。パフェの飛び道具、音波、スライディングキックなどの効果はゲーム用の改変で、原作の台詞や超能力設定を追加したものではありません。
