# 藤都子·巨羊羹

剧情来自《BanG Dream! YUME∞MITA》第12集：都子面对薇欧拉，从背后拔出律送给她的巨大羊羹，并喊出“我说的就是，这样太无聊了”。参考原片的竹皮外包装、米白纸带、黑色文字及深红豆沙切面。游戏将拿出羊羹威慑的剧情改编为前方横扫击倒；横扫造成伤害属于游戏设计。

新增技能「巨羊羹·这样太无聊了」使用↓＋I，消耗25共鸣，28基础伤害，前方310范围、240ms前摇、3.2秒冷却；受共享连段和防御规则影响。保留普通I、其他技能和九段大招。角色使用现有重击蓄力、挥击与收势动作，并叠加完整羊羹和挥击弧线。

语音裁自[动画片段](https://www.bilibili.com/video/BV1Zttf6KEzU/)的0–8.4秒，原速完整说完，未使用后续插入的其他动画画面。起止时间、原句、说话人核对与音频哈希见 `sources.json`；临时逐帧证明与词级定位结果保存在忽略目录 `output/miyako-yokan/`。

重新导出：`python tools/build_miyako_yokan.py --source-video <原片.mp4>`；仅重新打包已有音频时省略参数。完整素材构建也通过 `tools/build_meme_assets.py` 接入同一资料，运行文件使用内容哈希命名。
