# 藤都子・巨大羊羹

物語は『BanG Dream! YUME∞MITA』第12話から来ています。薇欧拉を前に、藤都子は峰月律から贈られた巨大な羊羹を背中から抜き、「我说的就是，这样太无聊了」と叫びます。原映像の竹皮の外装、生成りの紙帯、黒い文字、濃い小豆色の断面を参考にしています。ゲームでは羊羹を出して威嚇する場面を前方への横薙ぎ・ダウンに改変しており、横薙ぎのダメージはゲームデザインです。

新しいスキル「巨羊羹·这样太无聊了」は↓＋I を使い、25共鳴を消費、基礎28ダメージ、前方310の範囲、発生240ms、クールダウン3.2秒です。共通のコンボとガードのルールに従います。通常のI、その他のスキル、9段の必殺技は維持します。キャラクターは既存の強攻撃の溜め・振り・収めの動作を使い、完全な羊羹と振りの軌道を重ねます。

ボイスは[アニメ映像](https://www.bilibili.com/video/BV1Zttf6KEzU/)の0–8.4秒から切り出し、原速で最後まで言い切っています。その後に挿入される別のアニメ映像は使っていません。開始・終了時刻、元の台詞、話者の確認、音声ハッシュは `sources.json` にあります。一時的なフレーム単位の確認と単語単位の位置特定の結果は、無視対象のディレクトリ `output/miyako-yokan/` に保存しています。

再エクスポート：`python tools/build_miyako_yokan.py --source-video <原片.mp4>`。既存音声の再パックのみの場合は引数を省略します。完全な素材ビルドも `tools/build_meme_assets.py` 経由で同じ資料を取り込み、実行ファイルは内容ハッシュで命名されます。
