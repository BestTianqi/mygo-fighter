# 立希：アニメ台詞の差し替え

公式30秒「キャラクター紹介CM・椎名立希篇」から6つのアニメ台詞を選びました。声は立希本人の林鼓子です。公式の原映像は[BanG Dream Channel☆](https://www.youtube.com/watch?v=UH6zMjECvQo)で、公式[キャラクター資料](https://anime.bang-dream.com/mygo/character/taki/)でCVと外見を確認できます。今回のダウンロード元は[花园多惠Officialによる原CMの転載、第5P](https://www.bilibili.com/video/BV1i14y1U7DP/?p=5)、CID `1173143579` です。この転載アカウントは公式アカウントではないため、出典記録では原配信元と転載者を明確に区別しています。

立希の焦げ茶のロングヘア、紫の目、口の動きをフレーム単位で確認し、日本語の単語タイムスタンプで切れ目を再確認しました。CM 内の同僚の台詞と愛音の注文の声は除外しています。AI 音声、配信者の声、MAD の継ぎ合わせは使っていません。音波・ドラム・キャラクターの台詞の組み合わせは本ゲームの技としての改変で、元の録音がアニメの超能力だと主張するものではありません。

P の録音と映像はどちらも原映像の19.55–22.38秒、完全な2.83秒の区間です。公式CMはこの区間で制服の寄りから店員服の場面へ切り替わっており、本プロジェクトはその元の編集をそのまま残しています。2つの台詞とその間の沈黙を保ち、音声・映像とも原速で、より速い戦闘での発動から独立しています。奥義アートは同じ区間の20.60秒の制服立希の寄りで、`assets/finish-art/taki-anime-composer.webp` にあります。

各区間の `sources.json` は `character:'taki'`、明示的な技のmove、音源key、BV/CID/分P、元のアップロードURL、ダウンロード転載のメタデータ、話者の確認、SHA-256 を記録しています。`install.json` は独立した接続資料で、ブラウザで読み込む必要はありません。旧「哈？」の素材は残しています。

方向技／強化技の推奨：↓＋Uとその強化はUを、前＋Iとその強化はOを再利用します。滚奏・突進・低音波・八拍の四拍強化はそれぞれ元の技の音源を再利用し、追加の低音波はIを使います。P は完全な録音を最後まで再生し続ける必要があり、キャラクターの復帰動作や後続スキルで途切れてはいけません。
