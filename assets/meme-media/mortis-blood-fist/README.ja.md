# Mortis・拳が血を欲しがっている

このスキルは若葉睦の Ave Mujica ステージ形態でのみ使え、↓＋O で60共鳴を消費します。まず踏み込んで拳を出し、基礎20ダメージ（ステージ形態の既存1.2倍で24）を与えます。拳を放った後は、命中・空振りを問わず10秒間40%の吸血を得ます。最初の拳は先に精算してから新しい効果を得るため、すでにある吸血もこの一撃に作用します。

通常攻撃・スキル・必殺技は、相手が実際に失った体力の40%を回復し、ガード・シールド・軽減・コンボ・残り体力の影響を受けます。シールドで完全に吸収した場合、無敵中、体力が減っていない場合、召喚物にしか当たっていない場合は回復しません。回復は200体力までで、体力表示と計算は小数第1位を保持します。再発動で10秒を更新し、割合は重複しません。一時停止とヒットストップは既存の戦闘タイマーに従います。変身を解除しても残り時間の10秒効果は残り、ダウン・ラウンド精算・リスタートで消え、リレーでの入れ替えでは吸血を持ち越しません。クールダウンは3秒で、エネルギー条件は引き続き必要です。

動作は踏み込み・拳の溜め・ストレート・拳の収めで構成し、赤い拳圧、持続する吸血オーラ、HUDのカウントダウンを添えます。実際の回復は既存の体力回復のポップ表示を使います。U/I/O、「我只有两岁」、「我要吃汉堡」、必殺技はいずれも維持します。

ボイスはユーザー指定の[中国語の二次創作ミーム動画](https://www.bilibili.com/video/BV1Nxt96AERy/)から4.55–7.1秒を切り出した「注意，我的拳头想喝血了」です。動画内の吹き替え版であり、アニメ本編や声優の原音として扱っていません。今回、別途の声真似や加速も行っていません。元の台詞、字幕の確認、時間帯、音声ハッシュは sources.json にあります。一時的な画面確認と単語単位の位置特定は、無視対象のディレクトリ output/mortis-blood-fist/ に残しています。

再エクスポート：`python tools/build_mortis_blood_fist.py --source-video <原片.mp4>`。既存音声の再パックのみの場合は引数を省略します。完全な素材ビルドも `tools/build_meme_assets.py` 経由で同じ資料を取り込みます。
