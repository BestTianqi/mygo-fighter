# Mortis·我的拳头想喝血了

技能仅在若叶睦的Mujica演出形态可用，按↓＋O，消耗60共鸣。先向前踏步出拳，造成20基础伤害（演出形态既有1.2倍率后为24）；拳头释放后，不论命中或挥空，获得10秒40%吸血。首次出拳先结算，再获得新效果；已有吸血仍可作用于这次拳击。

普攻、技能与大招按对手实际损失的生命值恢复40%，受防御、护盾、减伤、连段和剩余血量影响。护盾完全吸收、无敌、没有扣血或只打中召唤物时不回血。回血不超过200生命，生命显示与计算保留一位小数。重复释放刷新10秒，不叠加比例；暂停和命中停顿遵循现有战斗计时。解除变身后保留尚未结束的10秒效果，击倒、回合结算和重开清除效果，车轮换场不携带吸血。冷却为3秒，仍须满足能量条件。

动作采用前踏、蓄拳、直拳与收拳，配红色拳劲、持续吸血光环和HUD倒计时；实际回血沿用生命恢复飘字。U/I/O、我只有两岁、我要吃汉堡及大招均保留。

语音来自用户指定的[中文二创梗视频](https://www.bilibili.com/video/BV1Nxt96AERy/)，剪取4.55–7.1秒“注意，我的拳头想喝血了”。这是视频中的配音版本，未将其标注成动画或声优原声；本次未另行仿声或加速。原句、字幕核对、时间段与音频哈希见 `sources.json`，临时核对画面和词级定位留在忽略目录 `output/mortis-blood-fist/`。
