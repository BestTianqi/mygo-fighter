# 客服小祥・少々お待ちください

通常形態の祥子 ↓＋U（2P：↓＋テンキー4）、20共鳴、クールダウン2.4秒。180msで前方に電話の音波を1回出します。基礎14ダメージ、硬直550ms、ガード可能で、通常命中で2共鳴回復します。既存の通常形態Uとステージ形態の技は維持します。

ボイスは公式の2025年エイプリルフール「ミネラル天然ライフ」の客服祥子イベントから取っています。参考：[公式イベント](https://bang-dream.com/mineralnaturallife/)、[Naohito_futa の字幕付き画面録画](https://www.bilibili.com/video/BV1sGZbY6E8H/)。動画第1P、cid 25779115564、69.25–70.95秒、「今しばらくお待ちください」。字幕・画面録画・日本語の文字起こしを照合してから裁断し、原速・原音程、音量の正規化とごく短いフェードイン／アウトを入れています。詳細な出典とSHA256は sources.json にあります。

customer-actions-source-v1.png は内蔵の image_gen が祥子の公式通常衣装を参考に新しく描いたものです。3つの実動作は順に、ヘッドセットに手を添える、掌を出して待つ、丁寧にお辞儀する、です。ビルド時に透明化したキャラクターを分離して拡大縮小してパックし、既存の動作アトラスは差し替えていません。
