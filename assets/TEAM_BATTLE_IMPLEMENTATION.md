# 选人与3v3车轮战

开始游戏、电脑对战、同屏双人和练习均先进入选人界面。主菜单另设3v3入口；选人界面可切换赛制与对手模式。现有十五名角色全部可选，练习固定为1v1。确认阵容后才开始加载对战。

## 阵容与胜负

- 3v3每队三人，按槽位顺序出场；同队不能重复，双方允许镜像选择。
- 出场者各200生命。胜者保留当前生命、能量和立希鼓点；下一人以200生命、0能量登场。
- 击败一人后自动经过1200毫秒过场和1000毫秒准备，进入下一场；每场重新计时60秒。
- 超时按剩余生命判断胜负；相等或双倒时双方均退场。任一队三人耗尽即结束，同时耗尽为平局。
- 换场重置站位和临时状态，清除弹体、召唤物、范围效果、控制、变身以及语音视频。
- 头像队列显示当前、候补和退场成员。暂停和返回菜单冻结换人倒计时。
- 取消新选人保留原暂停对局；重启沿用已确认的阵容，双方从第一人重新开始。

## 接入

`src/selection.js`负责可编辑阵容、角色去重、模式切换和完整阵容确认。`src/app.js`在确认后预备全部六人的所有形态素材，驱动队伍头像与对战反馈。`src/engine.js`负责队列推进、资源继承、自动换人和队伍胜负。

原有1v1赛制、角色技能和操作键位保留。页面继续使用内嵌离线素材，不需要网络或额外服务，最终入口为仓库根目录`index.html`。

## 验证

- Node战斗与操作测试338项，包含6项选人状态测试、16项车轮战测试。
- 素材、构建和离线一致性检查34项。
- `tests/team_selection_browser.py`覆盖实际选人、六人确认、完整车轮战、自动换人、双方后备角色技能、胜者资源继承、电脑换人后继续战斗、重启、选人取消与手机触控。
- `tests/main_menu_browser.py`覆盖原有菜单和1v1流程，以及390、844和667像素宽度下的菜单触控尺寸。
- `tests/meme_skills_browser.py --characters 0 1`验证原声与视频技能，以及打开选人后取消并恢复旧对局时的媒体续播。
