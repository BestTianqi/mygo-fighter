# 奥義フィニッシュ背景動画

16 人のキャラクターの無音クリップで、`../sources-voices.json` で確認済みの原映像と開始・終了時間をそのまま使っています。対応する記録は `../sources-videos.json` にあります。話者の差し替え、加速、繰り返し再生は行わず、音声の元のセリフと原速を保っています。

動画は 640×360、24 fps の H.264 で書き出し、音声トラックは含みません。実行時は奥義イラストの下にぼかして表示し、フィニッシュボイスの実際の再生位置に追従します。元の音声を無音で埋めた末尾はフリーズフレームで補います。動画の読み込みに失敗した場合も奥義イラストは表示され、場面転換はボイスの完了状態で制御されます。

切り直すときは `python tools/build_finish_videos.py --source-dir <包含BV编号.mp4的原片目录>` を実行し、続けて `python tools/build_finish_assets.py` でパックしてください。原映像は実行時アセットに含める必要はありません。
