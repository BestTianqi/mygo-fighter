# フィニッシュ奥義ボイス v2

16 人の基本キャラクターにそれぞれ 1 本のフィニッシュボイスがあります。2026-10-30 に、ユーザー指定の出典に基づいて愛音、そよ、燈、祥子のリザルト動画とボイスを差し替えました。必殺技を放つときの素材とイラストは変わりません。バインドキーは `finish_0` から `finish_15` までで、出典、元のセリフ、話者確認の根拠、開始・終了時間は親ディレクトリの `sources-voices.json` にあります。

音声はすべて原速のまま、モノラルの MP3 で、ラウドネスは約 -18 LUFS です。旧アニメのセリフの本人確認は引き続き有効です。今回の愛音と燈はユーザー指定のミームであり、公式声優の原音であるとは主張しません。祥子は原映像の最後の 8 秒を使い、その中のそよの前のセリフの末尾と祥子のセリフの完全な原音を残すことをユーザーが明確に承認したため、mixed と表記しています。そよはアニメ本人の完全な 1 文のままです。

今回祥子のために指定された混合対話の区間を除き、Mujica は引き続き本人の基本ボイスを共有します。睦のこの 1 本は通常の睦であり、Mortis 専用のセリフとしては扱っていません。ペンギンと通常の燈は、今回指定された燈のミームの断片を共有します。これらの音声トラックは撃破フィニッシュのイベントで選ばれ、必殺技の掛け声の原音には影響しません。

一時的なネット検索結果、ダウンロードした原映像、原映像のメタデータ、単語レベルの ASR 位置合わせ結果、確認用の画面は、無視対象のディレクトリ `output/finish-art-v2/voices/` に保存しており、実行時アセットには含めません。原映像の確認が人物の同一性の根拠で、ASR は位置合わせを補助するだけです。初華のセリフはアニメ自体の鏡像／心の声ですが、キャラクター本人の声です。

以前の愛音とそよの 2 秒の無音パディングは、今回指定された出典に置き換えました。千石由乃の 1.50 秒の完全な応答にはさらに 0.50 秒の無音を足し、背景は最後のフレームで止まります。キャラクターの話す速さは元のままです。
