# 奥義リザルト画像

- `anon-milk-dragon-v1.png`：千早愛音。ピンクの髪に黄色いミルクドラゴンのスキンで、スキンの色は必殺技の動作と一致しています。
- `tomori-penguin-v1.png`：高松燈。凑企鹅（ペンギン）形態です。
- `miyako-super-background-v1.webp`：藤都子の必殺技動画 `assets/meme-media/recordings/miyako-p.mp4` の 9 秒目の魔法陣の画面で、元画像の比率を保ち、全幅の奥義背景として使っています。

愛音と燈の 2 枚は、ゲームに既存の変身動作画像を参考に画像生成で制作し、透過背景を保っています。藤都子の画像は既存の必殺技動画からそのまま取得しました。`python tools/build_finish_assets.py` を実行すると実行時アセットを更新できます。選択中キャラクターの奥義画像はバトル開始前にプリロードされます。

必殺技での撃破専用の全キャラクター横長シーン画像と新しいフィニッシュボイスは [v2/README.md](v2/README.ja.md) にあります。上記の古い画像は通常の撃破リザルトで引き続き使用します。
