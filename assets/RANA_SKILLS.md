# 要乐奈 · 吉他与野猫步伐

已接入 `index.html`。定位为灵巧突进型：移速约537、跳跃初速约1332，冲刺沿用全角色即时冲刺。基础拳脚通常较爱音低1点，另有J键三段派生，站立、蹲下与空中各有轻中重掌/吉他与轻中重脚，共18种普通攻击。

普通攻击命中可接更重普通技或必杀，必杀命中可接P。空中普通技命中可接F，每次跳跃只有一次空中普通行动，落地重置。弦波支持防御、钢板吸收、与对方飞行物抵消及地形碰撞。调弦、技能和冷却遵守暂停、命中停顿、重开与回合重置。

2P沿用六键：小键盘1/7/2为轻中重掌/吉他，8/9/.为轻中重脚；4拨弦、Enter强奏、End抹茶芭菲、Home突进、+上挑、*滑踢、PageDown空中俯冲、Delete调弦、3独奏、−大招、5投技。手机按钮随所选角色显示相应名称。游戏内F1提供完整招式表。电脑会依据距离、对方高度与能量选择芭菲、突进、弦波、上挑、滑踢、独奏和调弦。
