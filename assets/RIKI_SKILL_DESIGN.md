# 椎名立希 · 技能设计

状态：已接入选人、战斗与动作素材。立希为第五位可玩角色；现有乐奈同样保留完整实战支持。

## 定位与基础动作

定位为「鼓点重击 / 近身压制」：双鼓棒进行短促连打，利用突进、对空和中段打开防守，再用积累的节拍强化招式。优势为重击反馈和近身连段；弱点为远程能力有限、重招落空收招较长。

当前生命200，共鸣上限100，步行速度330，跳跃初速度620，沿用现有冲刺、空中转向、按键缓冲与离台起跳宽限。保持正常动画头身比和官方2D脸，服装与现有人物使用一致的立绘参考方式。

J/H/K为轻、中、重鼓棒攻击，N/M/逗号为轻、中、重脚；提供站立、蹲下、空中共18种普通攻击。B投技，O防御，Shift冲刺。重棒攻击起手稍慢，配合明显的下压重心、鼓点和回弹动作。初版站立拳脚伤害依次为7/11/20/6/10/17，蹲下与空中按现有规则区分攻击段位。

## 四拍节奏

- 普通攻击实际命中后增加1层节拍，最多4层；每次普通攻击只计一次。空挥、格挡、投技和特殊技不增加节拍。
- 满4层时，下一个I/C/U/T/Y特殊技自动消耗全部节拍并得到专属强化。能量不足或空地条件不允许发动时不消耗节拍；成功发动后落空或被打断仍消耗。
- 强化主要改变推进距离、对空轨迹、音波数量或收招，不统一乘伤害倍率；避免重招与连段衰减叠加后失控。
- G、L、P不消耗节拍。暂停冻结计时，回合开始或重开清零。
- 使用现有角色状态栏显示「节拍 0/4」，满层提示下一招强化，不增加舞台外信息面板。

I/C/U/T/G/L/P地面或平台施放；Y可从地面起跳对空，初版不额外提供空中必杀。T不会追踪不同高度的平台，遇实体地形消失。强化T的第二道波同样受地形与护盾影响，未发射前被打断就取消。

L的八段不能自动追踪远处敌人。P虽然有舞台灯光和鼓面特写效果，实际伤害范围仍跟随人物在地图中的位置；不清空整张大地图，不更换地图，不瞬移目标。P格挡磨血三段为2/2/4，沿用现有连段和能量规则。

G发动时消耗共鸣并开始冷却，补节拍在300ms生效，被打断不返还能量；暂停冻结，重开清理。不得通过G刷新自身冷却。

## 键位与连招

1P沿用现有字母键。2P的I/C/U/T/Y/G/L/P分别为小键盘4、Home、小键盘*、小键盘Enter、小键盘+、Delete、小键盘3、小键盘减号。18种普通攻击和投技使用与爱音一致的六键与小键盘5。手机按钮随选人显示对应名称。

- 入门：J → H → C，普通攻击确认后用抢拍接近。
- 连打路线：J → H → C → I；C命中允许接I，I末段命中允许接L。
- 消耗：蹲轻脚 → T，打中对手下盘后拉开。
- 破蹲防：U命中后接J → H，再选择I或L；U接J仅在强化版增加硬直后提供稳定窗口，普通版不保证连段。
- 满资源：普通技确认 → L末段 → P；取消点只开放在L末段实际命中后，不能从前七段直接取消。

伤害按现有连段衰减执行，空挥不能取消。强化I仅减少命中后的收招，不让被挡后的重击形成无限压制；C的靠近效果和强化Y跟进都要遵守角色碰撞与世界边界。

## 动作与视听方向

动作表现为紧凑、直接、有下压重心的鼓棒攻击。待机握紧双棒，移动时收拢手臂；滚奏左右交替，上挑向上挑棒，砸击双棒举起后落下，G有清晰的两下校拍动作。与素世的掌击和灯的麦克风施法分开制作。

攻击主色采用冷紫、白色与少量暗红重拍线条。轻击使用短军鼓声，C配踩镲声，T配低音鼓，L形成八拍节奏，P三次重鼓分别与实际命中窗口同步。现阶段设计为本地合成打击乐，不默认使用演员语音或其他视频音轨。

## 制作与验收顺序

先制作正常身材立绘和移动、防御、受击等基础动作，再实现18种普通攻击、I/C/U/T/Y、节拍与G、L和P。所有动作需独立校验面部、制服配色和落地锚点。

战斗验证覆盖：四拍仅由真实普攻命中叠加、同招不重复叠层、强化失败不误扣、两名立希资源独立、G打断与冷却、对空与平台高度、I/L多段中断、U站防/蹲防、T波护盾和抵消、P起手/范围/格挡、取消点与连段衰减，以及键盘、2P和手机触屏。
