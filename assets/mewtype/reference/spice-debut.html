バンドリ！プロジェクトより、新バンド「夢限大みゅーたいぷ」が始動&デビュー配信も決定

ニュース
アニメ/ゲーム
2023.11.10

(C)BanG Dream! Project

画像を全て表示（6件）

バンドリ！プロジェクトの夢（バーチャル）と現実（リアル）を飛び越える運命共同体(バンド)「夢限大みゅーたいぷ」(読み：むげんだいみゅーたいぷ)の活動がスタートすることが発表された。


◆仲町あられ

仲町あられ (C)BanG Dream! Project

◆宮永ののか

宮永ののか (C)BanG Dream! Project

◆峰月律

峰月律 (C)BanG Dream! Project

◆藤都子

藤都子 (C)BanG Dream! Project

◆千石ユノ

千石ユノ (C)BanG Dream! Project


 

メンバーは、Vo. 仲町あられ、Gt. 宮永ののか、Gt. 峰月律、Key. 藤都子、DJ & Mp. 千石ユノの5名で構成。11月18日(土)・19日(日)にはメンバー5名のデビュー生配信を予定している。

それぞれYouTube上での生配信や動画投稿に加えて、実際に楽器を演奏しての音楽活動を行い、2024年には1st LIVE「めたもるふぉーぜ」を開催するとのこと。

バンドリ！プロジェクトの新バンド「夢限大みゅーたいぷ」に注目していきたい。
