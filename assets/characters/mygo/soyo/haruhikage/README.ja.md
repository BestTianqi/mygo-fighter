ラウンド終了時、長崎そよはこの動画の切り出しフレームをアクション立ち絵の代わりに使用します。バナー画像は右側でフェードアウトして勝利テキストにつなげ、表示時にもともと暗い映像を明るくします。元画像の色は変えず、オフラインに埋め込み、対戦開始前にプリロードします。

横画面動画の音声トラックを使う場合は、MP3 を同時に再生しないでください。セリフが重なります。既存の Web Audio 音声システムに接続する場合は、ミュートした動画と MP3 の組み合わせが使えます。

## 検証

- 横画面の元クリップをフレーム単位で確認しました。セリフの字幕は「为什么要演奏春日影」です。
- 納品した 3 ファイルはすべて完全にデコードして確認しました。Web 再生と音声デコードの結果は `verification.json` に記録しています。
- 具体的な切り出し範囲、出典リンク、ファイルのチェックサムは `sources.json` にあります。

## ゲームへの組み込み

長崎そよを選び、共鳴 100 で P を押します（2P テンキーの −、タッチでは「春日影大招」）。サウンドエフェクトを有効にすると元音声が再生され、映像はセリフの重複を避けるため常にミュートです。3 段のダメージは 8/12/28 で、通常はコンボ減衰後に合計 41、最後の段でダウンします。一時停止すると映像と音声も同期して停止し、再開すると停止位置から続きます。被弾による中断、ラウンド終了、再開始のいずれでも再生をクリアします。映像と音声はいずれも `index.html` に埋め込まれており、ネットワークに依存しません。
