# Mujica マスク変身アクション

内蔵の imagegen を使い、各キャラクターの既存の私服とステージ衣装の立ち絵を参照して、3 枚の完全な全身アクションをそれぞれ描き起こしました。通常のアニメ体型と衣装の色を保っています。5 枚の元 PNG、抽出後のアトラス、フレーム情報はすべてこのディレクトリに保存しています。参考ファイルと元画像のハッシュは sources.json に記載しています。

アクションプロンプト：同じ身長の完全な全身人物 3 体を横に並べ、左は私服で胸の前で両手にマスクを持ち、中は私服で手を上げてマスクを着け、右はステージ衣装でマスクを着けた後に両手を下ろした姿。八幡海鈴と若葉睦は鼻と口を、豊川祥子・三角初華・祐天寺にゃむは目元を覆います。元キャラクターの顔立ち・髪・衣装を保ち、7 頭身、非デフォルメ、透過背景、楽器とエフェクトなし、髪と靴は完全に描きます。

H 変身後は 0–220ms がマスク所持、220–440ms が装着、440–720ms が完了ポーズです。最初の 2 フレームは私服のまま、3 フレーム目でステージ衣装に切り替わります。440ms で拡散するオーラが発生し、立ち上る粒子と光輪は 1100ms までにフェードアウトします。動きを減らす設定が有効な場合は弱まります。アクションは演出のみで、ステージスキルは即座に付与され、技のロックや無敵時間は増えません。移動・攻撃・被弾などは通常の戦闘アクションを優先します。

tools/build_mask_assets.py で透過連結領域ごとに抽出しており、元の立ち絵と 560 枚の二形態アクションはそのまま保持しています。
