# Mujica 戴面具变身动作

使用内置 imagegen，参照每个角色已有的常服与演出服立绘分别绘制三张完整全身动作，保持正常动画身材与服装颜色。五个原始PNG、提取后的图集、帧信息均保存在本目录；参考文件和原图哈希见 sources.json。

动作提示词：三个同高完整全身人物横向排列，左为常服双手在胸前持面具，中为常服抬手戴上面具，右为演出服戴好面具后放下双手；海铃／睦遮鼻口，祥子／初华／若麦遮眼部。保持原角色五官、头发、服装，七头身、非Q版，透明背景，无乐器和特效，完整头发与鞋子。

H变身后0–220ms为持面具，220–440ms为戴上，440–720ms为完成姿态。前两帧保留常服，第三帧换演出服。440ms爆出扩散气场，上涌粒子与光环至1100ms淡出；开启减少动态效果时减弱。动作纯表现，仍立即获得演出技能，不增加出招锁定或无敌。移动、攻击、受击等以正常战斗动作优先。

通过 tools/build_mask_assets.py 按透明连通区域提取，原立绘及560张双形态动作保持原样。
