# Mujica 立ち絵と画面改善 · 2026-10-23

内蔵の image_gen を使い、ローカルに保存した公式 2D 参考をもとに 5 人の私服とステージ衣装の全身立ち絵を計 10 枚描きました。通常の体型、各人の目の形・髪色・衣装を保っています。八幡海鈴と若葉睦は口元を覆うマスク、豊川祥子・三角初華・祐天寺にゃむは目元を覆うマスクです。

最終採用：八幡海鈴・三角初華・祐天寺にゃむは source-v2、豊川祥子は source-v3、若葉睦は source-v4。source-v3 は透過エッジの修正版です。若葉睦の v4 はスカートの裾が触れないよう、2 体の完全な人物を分離しています。原稿はいずれも保持しています。各人の最初の完全なプロンプトと参考ファイルは sources.json、修正プロンプトは revisions.json に別途記録しています。

tools/build_portrait_assets.py は透過チャンネル付きの全身立ち絵、独立して中央揃えした顔サムネイル、235 ワールド単位の高さの待機フレームを生成します。キャラ選択画面、メインメニュー、チームの顔アイコン、実戦の待機はいずれも同じ素材セットを使用します。既存の二形態の攻撃・移動・マスクアクションは保持し、さらにアニメーション層に、移動距離に応じた歩調と足裏固定によるわずかな上半身の動きを加えています。
