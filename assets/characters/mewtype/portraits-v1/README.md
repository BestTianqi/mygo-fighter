# 梦限大五人立绘

仲町阿拉蕾（10）、峰月律（11）、藤都子（12）、千石由乃（13）、宫永野乃花（14）使用初始虚拟服装，正常身材比例与透明背景。

`*-source-v1.png` 为使用图像生成工具重绘的全身图；参考来自 `../reference/` 保存的初始形象，藤都子的全身服装同时参考现有 `../miyako/virtual-idle.webp`。这些重绘不冒充官方素材。

`crops.json` 记录头像裁切。运行 `python tools/build_mewtype_portraits.py` 生成全身预览、方形头像和待机图集，并更新运行素材。菜单、选人、头像、普通结算和待机使用新图；攻击和移动继续使用各角色已有动作图集。
