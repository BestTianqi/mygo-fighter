# MewType 5 人の立ち絵

仲町阿拉蕾（10）、峰月律（11）、藤都子（12）、千石由乃（13）、宫永野乃花（14）は初期バーチャル衣装を使用しており、通常の体型比率と透過背景で描いています。

`*-source-v1.png` は画像生成ツールで描き直した全身図です。参考は `../reference/` に保存された初期デザインで、藤都子の全身衣装は既存の `../miyako/virtual-idle.webp` も参考にしています。これらの描き直しは公式素材の代用ではありません。

`crops.json` は顔アイコンの切り抜きを記録しています。`python tools/build_mewtype_portraits.py` を実行すると、全身プレビュー、正方形の顔アイコン、待機アトラスを生成し、実行時素材を更新します。メニュー、キャラクター選択、顔アイコン、通常リザルト、待機では新しい画像を使用し、攻撃と移動は各キャラクターの既存アクションアトラスを引き続き使用します。
