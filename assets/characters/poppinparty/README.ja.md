# Poppin'Party 未統合素材パック

5 人分の独立した立ち絵とスキル定義。**ゲームにはまだ追加していません**。

- `portraits/`：5 枚の 1024×1536 透過 PNG。原作 2D の顔、通常の体型、花咲川の制服。香澄は赤い星形ギター、たえは青いギター、りみはピンクのベース、沙綾は 2 本のドラムスティック、有咲はキーを押す手の仕草。
- `references/official-uniform-lineup.jpg`：[公式制服ビジュアルのニュース](https://gamebiz.jp/news/366083)の参考画像。人物は左からりみ、沙綾、香澄、有咲、たえ。
- `prompts.json`：内蔵 image_gen の元プロンプト、参考元、生成モード。
- `actions/`：各 16 種、計 80 種の独立したキーアクションポーズ。切り出し矩形、シルエット、表示倍率は `manifest.json` に保存。詳細は[アクション説明](actions/README.ja.md)。
- `action-prompts.json`、`action-generation.json`：アクション画像のプロンプト、参考、描き足しの記録。いずれも内蔵 image_gen を使用。
- `voices/`：公式ゲーム音声 30 本の出典、話者、原文、切り出し時間。各人に登場、U/I/O/P、フィニッシュの 6 本。詳細は[ボイス説明](voices/README.ja.md)。
- `skills.json`：55 の技に内部用のカウンターウェーブ 1 つを加えたもの。効果、判定、時間、ダメージ、動作説明を含み、正式な数値 ID は含みません。
- `preview.html`：ダブルクリックで立ち絵とスキル表の表示、アクション切替、J の 3 段再生、30 本のボイス試聴ができます。サーバー不要で、正式なゲームは読み込みません。

スキルのコード：`frontend/src/game/bands/poppinparty/draftMoves.ts`。ファクトリは将来正式に割り当てられる 5 つの ID を受け取り、データを返すだけで、自動登録の副作用はありません。`bands/index.ts` からはインポートされていません。エクスポーターが使う仮 ID を正式 ID と取り違えないでください。

再エクスポート：プロジェクトルートで `node tools/build_poppinparty_drafts.mjs` を実行します。この操作は 5 つのキャラクター JSON とオフラインプレビューを更新し、正式なアセットマニフェストは更新しません。

スキルは共有バトルカーネルで検証しています。両方向で計 110 回の解放を行い、エネルギー不足、基本コンボ減衰、カウンターと空振りウェーブ、シールドとその期限切れ、予告付き回避、前後の向き、必殺技のスーパーアーマーを確認しました。30 本のボイスはデコード、長さ、スキル参照、等速再生、排他的試聴を検証済みです。80 種のキーアクションは完全な切り出しと隣接する残像を確認し、3 段通常攻撃の切り替えとスキルボイスも検証しました。共有カーネルは変更していません。完全な連続フレームアニメーション、戦闘エフェクトの描画、奥義背景画像は今後制作する予定で、現時点でプレイ可能とは主張しません。
