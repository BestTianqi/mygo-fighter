# Poppin'Party 原声语音

共30条，五位成员各6条，分别对应入场、U/I/O/P及终结。后退派生复用对应基础技能语音。当前仅供离线素材包与试听页使用，尚未接入游戏名单。

来源为 B 站官方账号「BanGDream梦想协奏曲」发布的角色自我介绍与「1分钟了解」视频；内容为《BanG Dream! 少女乐团派对》的角色原声。不是新录制台词，也不是生成或变声语音。保留原片背景音，部分片段含音乐伴奏。

`sources.json` 记录每段的原视频BV号、标题、发布者、说话人、声优、原句、中文释义、起止秒数及播放时长。已通过官方角色标识、原片画面／字幕与逐段转写交叉核对。自动转写中的人名、乐队名等错误按原片修正；不将不同角色的回答混入同一人的技能语音。

所有片段原速播放，单声道44.1kHz MP3 80kbps，响度目标-18 LUFS，边缘8/20ms淡入淡出。香澄P使用自我介绍中的「星之鼓动」叙述，排除了回顾视频中混入的歌曲段落。里美终结保留完整请求支持的句子。

在项目根目录执行：

```powershell
python tools/build_poppinparty_voices.py --source-dir output/poppinparty
node tools/build_poppinparty_drafts.mjs
```

原视频输入以 `BV号.mp4` 命名，放在忽略的 `output/`；不把整段原视频放入游戏资源。打开上一级的 `preview.html` 即可逐条试听，同一时间只播放一条。
