# Poppin'Party 原音ボイス

全 30 本、各メンバー 6 本で、登場、U/I/O/P、フィニッシュに対応します。後退派生は対応する基本スキルのボイスを再利用します。現在はオフライン素材パックと試聴ページでのみ使用しており、ゲームのロスターにはまだ組み込んでいません。

出典は Bilibili の公式アカウント「BanGDream梦想协奏曲」が公開したキャラクター自己紹介と「1 分でわかる」動画で、内容は『BanG Dream! ガールズバンドパーティ！』のキャラクター原音です。新規収録のセリフでも、生成や声質変換をした音声でもありません。元映像の背景音を保持しており、一部のクリップには音楽の伴奏が含まれます。

`sources.json` は各クリップの元動画の BV 番号、タイトル、投稿者、話者、声優、原文、中国語の意味、開始・終了秒、再生時間を記録しています。公式のキャラクター識別、元映像の画面と字幕、区間ごとの文字起こしで照合済みです。自動文字起こしでの人名・バンド名などの誤りは元映像に合わせて修正し、別キャラクターの回答を同じ人物のスキルボイスに混ぜることはしていません。

すべてのクリップは等速再生で、モノラル 44.1kHz MP3 80kbps、ラウドネス目標 -18 LUFS、端に 8/20ms のフェードイン／アウトを付けています。香澄の P は自己紹介の「星の鼓動」の語りを使い、振り返り動画に混ざった楽曲パートは除外しました。りみのフィニッシュは応援を求める完全な文を保持しています。

プロジェクトルートで実行します：

```powershell
python tools/build_poppinparty_voices.py --source-dir output/poppinparty
node tools/build_poppinparty_drafts.mjs
```

元動画は `BV号.mp4` という名前で、無視対象の `output/` に置きます。元動画の全体をゲーム素材には入れません。1 つ上の `preview.html` を開けば 1 本ずつ試聴でき、同時に再生されるのは 1 本だけです。
