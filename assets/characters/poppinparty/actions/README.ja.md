# Poppin'Party アクション画像

5 人それぞれ 16 種のキーポーズ、計 80 種：待機、歩行、走り、ジャンプ、ガード、被弾、ダウン、登場、J の 1／2／3 段、K、U/I/O/P。いずれも各人の承認済み立ち絵をもとに内蔵 image_gen で生成しており、通常の比率と統一した花咲川の制服です。完全な作画記録は 1 つ上の `action-prompts.json` と `action-generation.json` にあります。

同名の PNG 5 枚が元のアクションアトラスを保存しています。さらに単体ポーズの補画 5 枚があり、アトラス内で余白が足りない有咲の登場、香澄の U/I、たえのジャンプ、りみの K を置き換えます。元のアトラスのその他のポーズは引き続き使用します。

`manifest.json` はキャラクターごとに、各アクションの元 PNG、切り出し矩形、シルエット、表示倍率、必要な反転を列挙しています。等幅グリッドで直接切り出すことはできません。一部の楽器や靴先が生成画像の名目上のセル線を越えており、シルエットは人物全体を残したまま隣接するポーズを除外できます。香澄の U はアクションの向きに合わせて反転表示し、りみの U は独立して投げ出したチョココロネを保持します。

元 PNG はピクセル単位では書き換えません。`python tools/build_poppinparty_actions.py` を実行すると透過チャンネルの分析と切り出し・シルエット資料の生成だけを行い、Pillow、NumPy、OpenCV が必要です。続いて `node tools/build_poppinparty_drafts.mjs` を実行するとプレビューとキャラクター資料を更新します。

`preview.js` は Canvas でこれらのアクションを表示します。1 つ上の `preview.html` ではアクションを 1 つずつ選び、J の 3 段を再生し、U/I/O/P と登場に対応するボイスを鳴らせます。アクションが待機に戻った後も、ボイスは元の速度で最後まで再生されます。

これはキーポーズの素材パックとアクション切り替えのデモで、各技の完全な連続フレームアニメーションは制作していません。正式なロスター、CPU、オンライン対戦、実行時アセットパックはいずれもこの素材パックを導入していません。
