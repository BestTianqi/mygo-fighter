# 3 人乱闘

メインメニューで「三人混战」を選ぶと、ローカルでは 1P が 2 体のコンピューターと戦います。各サイドが順番に 3 キャラクターを選びます。
オンラインでは、ホストが対戦モードを「三人混战」に設定し、残りの 2 人が同じルーム番号で参加します。3 人とも選択と準備を終えると対戦が始まります。
オンラインでは全員が自分の通常の 1P キーを使います。モード識別子は `3ffa`、プロトコルバージョンは 23 です。

- 3 キャラクターが同時に場に出て、それぞれが自分のために戦います。通常攻撃、強攻撃、範囲スキルは実際の範囲で他のプレイヤーに当たり、飛び道具は最初に触れた相手に当たります。
- 操作中のキャラクターが倒されると、そのサイドには 5 秒の控えカウントダウンが表示され、残りの 2 サイドは移動と攻撃を続けます。
- 5 秒後に選択順で次のキャラクターに自動で切り替わり、体力は満タン、エネルギーは最低 30、登場保護が 1 秒付きます。エネルギー無制限ルールでも 100 エネルギーのままです。
- 3 キャラクターを使い切ると敗退です。控えが残って待機中のプレイヤーは敗退になりません。最後に残ったサイドが勝利し、同時に全滅した場合は引き分けです。
- カスタムタイマーは通常どおり有効です。時間切れ時はまず残りキャラクター数、次に現在の体力を比べ、それでも同じなら引き分けです。時間無制限も有効にできます。
- 同じサイド内で同じキャラクターは選べませんが、別のプレイヤー同士では同じキャラクターを使えます。乱闘では BAN を有効にしません。ステージ、高低差のある地形、その他のカスタムバトルルールは通常どおり適用されます。
- 一時停止するとバトルと控えのカウントダウンが止まり、再開すると 3 人分の編成が完全に戻ります。誰かが切断した場合はオンライン対戦が一時停止し、切断中に敗退することはありません。
- 1 回の撃破では全画面の結果表示を出しません。試合が最終的に終わったときだけ結果を再生します。必殺技のフィニッシュでは、1 秒の奥義カットインと、セリフが終わってから進む仕組みを維持します。

実装はブラウザーと Scala/GraalJS サーバーで同じ 1 セットの戦闘ルールを共有しています。`npm run check` には、3 方向の入力、2 対象への攻撃、正確に 5000ms の控え交代、保護とエネルギー、同時敗退、第三者の勝利、一時停止と再開、スナップショットの回帰チェックが含まれます。
一時的なブラウザーと 3 端末のオンライン証跡は Git 管理外の `output/brawl/` ディレクトリに保存しています。

更新後はオンラインのホストを再起動し、3 人のプレイヤーに同じバージョンへ再読み込みしてもらってください。
