# 人物显示清晰度优化

2026-10-28：修复战斗画布与实际显示尺寸不匹配导致的全员模糊，保留原始人物图、脸型、配色、动作与特效。

## 实测变化

| 显示场景                       | 原画布像素 | 优化后画布像素 |
| ------------------------------ | ---------- | -------------- |
| 1920×1080，屏幕像素比 1        | 960×540    | 1920×1080      |
| 1440×810，屏幕像素比 2         | 1920×1080  | 2560×1440      |
| 手机 390×219.375，屏幕像素比 3 | 1920×1080  | 1170×658       |

原来普通大屏会直接放大 960×540 的整幅画面；现在根据画布实际 CSS 尺寸与屏幕像素比计算绘制分辨率。手机按需要绘制，避免无用的超大缓冲。尺寸由 ResizeObserver 追踪，离开游戏时释放观察器。

保留自动画质调节：持续掉帧时降低分辨率，稳定后恢复。最大缓冲约 2560×1440；超高分辨率屏幕受此上限约束。人物缓存保持 64 项、8 百万像素上限。

人物缓存的缩放分档改为向上取整，避免先缩得过小再拉大。达到原图像素密度时直接使用原始贴图。画布重置后重新启用高质量图像采样，保留头发、五官和服装线条。

Poppin'Party 离线动作预览同步按显示尺寸与像素比绘制，仍不接入正式名单。原始 PNG 及所有运行素材文件字节不变。

## 验证

- 缓存与分辨率检查：画布像素上限、向上采样、原始锚点与世界尺寸、缓存复用和内存上限。
- 真实浏览器：16 名可玩角色、Mujica 五个变身、灯企鹅、爱音奶龙，共 23 种显示状态；自动画质下降／恢复不改变战斗状态。
- 普通大屏、高分屏、手机及 Pages 子路径加载；全部资源正常。
- 五名 Poppin'Party 预览：普通屏、高分屏、手机、调整窗口、动作切换，无画布观察器错误。
- `npm run check`、`npm run build`、`npm run build:pages`。
