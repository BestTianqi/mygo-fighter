キャラクターの設定は[公式メンバー紹介](https://anime.bang-dream.com/bandorichan/character/poppinparty/)を参照してください。5 枚の立ち絵は[公式制服ビジュアルの参考](https://gamebiz.jp/news/366083)をもとに、内蔵の image_gen でそれぞれ生成し、正常な体型、各キャラクターの髪型と瞳の色、共通の制服を保っています。ソース画像、透明 PNG、完全なプロンプトは `assets/characters/poppinparty/` にあります。

スキル定義は `frontend/src/game/bands/poppinparty/draftMoves.ts` にあり、そのファクトリーは技データを返すだけで、グローバルレジストリを変更しません。セットには 55 個の技と沙綾の内部カウンター波 1 個、合計 56 個の定義が含まれます。共有戦闘カーネルに対してオフラインで検証済みで、正式なロスターはこのモジュールを読み込みません。

J の 3 段は基礎ダメージ 5／6／8、範囲 200。K は基礎ダメージ 13、範囲 240。後ろ＋U/I/O はいずれも飛び道具か投げです。通常の多段技は既存のコンボ減衰の影響を受けます。P はコンボ減衰を受けませんが、ガード、シールド、ダメージ軽減の影響は受けます。すべての技が必殺技のスーパーアーマーと共鳴のルールに従います。

## データの読み方

プロジェクトのルートで、たとえば次のように実行します：

```powershell
npm run character:read -- kasumi
npm run character:check -- kasumi
```

他のキャラクターは表の識別子に置き換えてください。次のように助手に直接伝えることもできます：「Poppin'Party の香澄の資料を読み、まず立ち絵を制作してください。ゲームへの接続はまだ行いません。」

5 つのファイルは既存のテンプレートを使い、`identity.codeBand` はすべて `poppinparty` です。現在このバンドは登録されておらず、数値 ID も割り当てられておらず、選択、CPU、3v3、オンラインのロスター、実行時アセットも変更していません。リーダーが表示する `ready-for-design` は、データ形式が使用可能という意味だけです。`node tools/build_poppinparty_drafts.mjs` を実行すると、スキル定義からデータ値とオフラインプレビューを再生成できます。

## 今後の制作

単独立ち絵、スキル定義、3 段弱攻撃と入場のアクション説明、および公式ゲーム音声 30 本（各メンバー 6 本）は制作済みです。プレビューページで試聴でき、完全な出典と切り出し時間は[ボイスデータ](../../assets/characters/poppinparty/voices/sources.json)にあります。変身が明確に必要になるまで `transformation.enabled: false` のままにしてください。

アクション画像も制作済みで、各メンバー 16 種類、合計 80 種類のキーポーズが、移動、ガード、被弾、入場、3 段弱攻撃、強攻撃、U/I/O/P をカバーします。プレビューページではポーズの切り替え、J の 3 段の再生、対応するスキルボイスでの実演ができます。アクションが終わってもセリフ全体は途切れません。ソース画像と切り出しリストは[アクション説明](../../assets/characters/poppinparty/actions/README.ja.md)にあります。完全な連続フレームアニメーション、奥義の背景アート、実戦へのアクション／エフェクト接続は今後制作します。

**ゲームへの接続は、ユーザーが明示的に追加を求めた後に行います。** 接続時は最新のレジストリから ID を割り当て、既存のキャラクター番号を保ち、[新キャラクターのテンプレート説明](README.ja.md)に従ってローカルとオンラインの検証を完了してください。
