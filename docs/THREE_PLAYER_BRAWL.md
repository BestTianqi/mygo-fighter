# 三人混战

主菜单选择「三人混战」，本地以 1P 对抗两名电脑；每方依次选择 3 名角色。
联机由房主把对战模式设为「三人混战」，另两位输入相同房间号加入，三人选齐并准备后一起开战。
联机每个人使用自己的普通 1P 键位。模式标识为 `3ffa`，协议版本 23。

- 三名角色同时在场，各自为战；普通攻击、重击和范围技能按实际范围命中其他玩家，飞行道具先碰到谁就命中谁。
- 当前角色被击倒后，该方显示 5 秒替补倒计时，另外两方继续移动与攻击。
- 5 秒后自动按选人顺序切换下一名角色，满血、至少 30 能量，入场保护 1 秒；无限能量规则仍为 100 能量。
- 三名角色耗尽后淘汰；还有替补但正在等待的玩家不算淘汰。最后剩余的一方获胜，同时全部淘汰则平局。
- 自定义计时照常生效；到时间先比较剩余角色数量，再比较当前血量，仍相同则平局。可启用无限时间。
- 每方内部不能重复选人，不同玩家之间可同角色；混战不启用 Ban。地图、高低地形及其他自定义战斗规则照常生效。
- 暂停会冻结战斗及替补倒计时，重开恢复三人的完整阵容。有人断线时联机暂停，不让其在掉线期间被淘汰。
- 单次击倒不弹出全屏结算；比赛最终结束时才播放结算。大招终结保留 1 秒奥义图切入与语音播完后的推进机制。

实现仍共享浏览器与 Scala/GraalJS 服务端的同一套战斗规则。`npm run check` 包含三路输入、双目标攻击、准确 5000ms 替补、保护与能量、同时淘汰、第三方获胜、暂停重开及快照的回归检查。
临时浏览器和三端联机证据保存在忽略目录 `output/brawl/`。

更新后重新启动联机主机，再让三位玩家刷新到同一版本。
