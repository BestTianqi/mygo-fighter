# 自定义对战规则

在本地选人或联机房间展开「自定义对战规则」。联机由房主统一设置，双方确认规则后准备开战。

| 选项           | 范围或效果                                                             |
| -------------- | ---------------------------------------------------------------------- |
| 出战人数       | 每方 1–8 人；2 人及以上按出战顺序进行车轮战                            |
| 每方禁用角色数 | 0–7 人，按当前队伍人数和角色池自动限制                                 |
| 生命值         | 每名角色 50–2000，默认 200                                             |
| 禁用大招       | 禁用 P 及其他输入方式触发的大招                                        |
| 无限能量       | 共鸣保持 100，技能、变身和瞬移均不消耗共鸣                             |
| 禁用普攻       | 禁用 J/K，包括三段普攻、重击、蹲下和空中普攻                           |
| 禁用变身       | 禁用 H，包括 Mujica 演出服和灯的企鹅形态                               |
| 无冷却         | 取消技能再次使用的冷却时间；保留出招、后摇、硬直和各技能自身的效果条件 |

「默认」恢复标准规则；「仅技能」开启无限能量并禁用普攻；「无限火力」开启无限能量和无冷却。预设也会恢复默认血量和零 Ban 位，可再自行调整。

零 Ban 位时，双方队伍可以使用相同角色，同一队内不能重复。开启 Ban 后，双方先交替禁人，再交替选择全场不重复的角色。现有 16 名角色下，5v5 最多每方禁 3 人，8v8 不设 Ban 位。练习模式仍为 1v1，无禁选，其他战斗开关可用。

改变人数或 Ban 位会重置进行中的禁选。联机改变血量或趣味规则会保留阵容并取消双方准备，避免在规则更改后直接开战。进入战斗后规则固定；需要返回选人或房间再修改。

血量上限同时用于开场、后续队员、回血、吸血和血条显示。普通车轮战的后续队员仍以 30 共鸣登场，无限能量下为 100。

规则由共享 TypeScript 战斗核心执行，浏览器本地战斗、联机预测和 Scala 权威模拟使用同一实现。房间协议为 21，更新后需重启主机服务，双方刷新网页。

验证：`npm run check` 包含自定义血量、回血、车轮战进度、全员动作禁用、电脑对手和能量/冷却检查；联机权限和禁选流程另经实际 HTTP/WebSocket 房间验证。

设计依据：2026-10-28，用户确认「按此方案直接实现，后续无需逐步确认」，并选择在当前目录修改。
