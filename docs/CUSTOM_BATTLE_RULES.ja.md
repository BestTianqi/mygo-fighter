# カスタムバトルルール

ローカルのキャラクター選択、またはオンラインルームで「自定义对战规则」を開きます。オンラインではホストが一括で設定し、両者がルールを確認してから準備開戦します。

| オプション                                   | 範囲または効果                                                                                                            |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 出战人数（出場人数）                         | 各陣営 1–8 人；2 人以上の場合は出場順にリレー対戦                                                                         |
| 每方禁用角色数（陣営ごとの使用禁止キャラ数） | 0–7 人；現在のチーム人数とキャラクタープールにより自動制限                                                                |
| 生命值（HP）                                 | キャラクターごとに 50–2000、既定 200                                                                                      |
| 禁用大招（必殺技の禁止）                     | P およびその他の入力で発動する必殺技を禁止                                                                                |
| 无限能量（無限共鳴）                         | 共鳴が 100 に保たれ、スキル、変身、ブリンクで共鳴を消費しない                                                             |
| 禁用普攻（通常攻撃の禁止）                   | J/K を禁止。3 段の通常攻撃、強攻撃、しゃがみ、空中通常攻撃を含む                                                          |
| 禁用变身（変身の禁止）                       | H を禁止。Mujica のステージ衣装と燈のペンギン形態を含む                                                                   |
| 无冷却（クールダウンなし）                   | スキル再使用までのクールダウンを撤廃；出の遅さ、後隙、硬直、各スキル固有の効果条件は維持                                  |
| 无限时间（無限時間）                         | ラウンドのカウントダウンを行わない；相手を倒した後の精算と交代は通常どおり                                                |
| 回合时长（ラウンド時間）                     | 1 ラウンド 30–300 秒、既定 60 秒；無限時間がオンの間はこの設定を使用しない                                                |
| 初始共鸣（初期共鳴）                         | 0–100、既定 0；リレー後続のメンバーは最低 30、勝者は残りの共鳴を保持                                                      |
| 伤害倍率（ダメージ倍率）                     | 0.5 / 1 / 1.5 / 2 / 3 倍。攻撃、ガード削り、召喚物へのダメージに適用                                                      |
| 移速倍率（移動速度倍率）                     | 0.75 / 1 / 1.25 / 1.5 / 2 倍。歩行、空中移動、ダッシュ速度、ブリンク距離に適用                                            |
| 一击决胜（一撃決着）                         | ガードされず実際にダメージを与えた攻撃は即座にダウン；シールドで完全吸収、ガード成功、カウンター時は発動しない              |
| 吸血对战（吸血対戦）                         | 実際に与えた HP ダメージの 25% を回復；キャラクター固有の吸血スキルとは高い方の比率を採用し、重複せず、最大 HP を超えない |
| 低重力                                       | キャラクターの重力が 60% になり、ジャンプが高く滞空が長くなる。CPU の経路探索も同じ物理パラメーターを使う                 |
| 无限空中跳跃（空中無限ジャンプ）             | 空中で連続してジャンプできる；硬直、攻撃モーション、マップ上端の制約は受ける                                              |
| 禁用防御（ガードの禁止）                     | スペースとバックステップで通常ガードが発動しなくなる；シールドとカウンタースキルは使用可能                                |

「默认」は標準ルールに戻し、「仅技能」は無限能量をオンにして普攻を禁止し、「无限火力」は無限時間、無限能量、クールダウンなしをオンにします。「一击决胜」「月面乱斗」「吸血拉锯」のお楽しみプリセットも使用でき、適用後もパラメーターを個別に調整できます。プリセットは HP、他のお楽しみスイッチ、Ban 枠ゼロの状態を再設定します。

Ban 枠がゼロのとき、両チームは同じキャラクターを使用できますが、同じチーム内で重複はできません。Ban を有効にすると、両者が交互に使用禁止を選び、その後、全体で重複しないキャラクターを交互に選択します。現在の 16 キャラクターでは、5v5 は各陣営最大 3 人まで禁止でき、8v8 では Ban 枠を設けません。プラクティスモードは 1v1 のままで、ピック／Ban はなく、他の戦闘スイッチは使用できます。

人数や Ban 枠を変更すると、進行中のピック／Ban はリセットされます。オンラインで HP やお楽しみルールを変更すると、編成は保持したまま双方の準備状態を取り消し、ルール変更直後の開戦を防ぎます。戦闘に入るとルールは固定され、変更するにはキャラ選択かルームに戻る必要があります。

HP 上限は、開始時、後続メンバー、回復、吸血、HP バーの表示に使われます。通常のリレーでは、後続メンバーは初期共鳴と 30 の大きい方で登場し、無限能量では 100 になります。

ルールは共有 TypeScript 戦闘コアで実行され、ブラウザのローカル戦闘、オンライン予測、Scala の権威シミュレーションが同じ実装を使います。ルームプロトコルは 22 で、更新後はホストサービスを再起動し、双方がページを再読み込みする必要があります。

検証：`npm run check` には、カスタム HP、回復、リレー進行、全員のモーション禁止、CPU 相手、エネルギー／クールダウン、無限時間、ダメージ／移動速度倍率、一撃決着、吸血、空中ルールのチェックが含まれます。オンラインの権限とピック／Ban の流れは、実際の HTTP/WebSocket ルームで別途検証しています。
